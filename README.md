Projectile Motion Simulation

A Python project that simulates projectile motion under different physical conditions.

Features

- Projectile trajectories at different launch angles.
- Air resistance and drag force.
- Wind effects on projectile motion.
- Variable air density simulation.
- Graph visualization using Matplotlib.

Technologies

- Python
- NumPy
- Matplotlib

Installation

Install the required libraries:

pip install -r requirements.txt

Run the simulation

python main.py

The simulation generates plots illustrating projectile trajectories under different conditions.

Output

- "projectile_simulation.png"
- "projectile_variable_density.png"
- "projectile_with_wind.png"
